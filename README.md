## 课程简介与修读流程

本课程为自动化系本科高年级的核心实践课程，集中在 **PLC / 工业自动化实验室** 开展：

- **硬件平台**：主要围绕西门子 S7-1200 系列 PLC、SINAMICS G120 变频器、步进电机及其驱动模块、模拟量扩展模块以及工控通信网络展开。
- **选题要求**：按课程指导书要求通常为“**6 选 4**”。本仓库涵盖了实际完成并顺利通过答辩验收的 **5 个核心选题**，可直接作为全套模板与参考：
  1. **选题 2（PID 温度控制）**：采用模拟量输入读取温度传感信号，利用西门子 `PID_Compact` 算法块进行参数整定与闭环控制。
  2. **选题 3（步进电机控制）**：通过 PLC 高速脉冲输出（PTO）与工艺对象轴控制指令（如 `MC_Power`、`MC_MoveRelative`）实现电机精确定位与调速。
  3. **选题 4（变频器 G120 控制）**：基于 PROFINET 工业以太网总线，配置标准报文（如 Standard Telegram 1），使用 `SINA_SPEED` 等控制字实现电机的启停、加减速与矢量控制。
  4. **选题 5（LabVIEW 与 PLC 通信）**：通过以太网（TCP/IP 或 OPC/S7 协议）实现上位机与下位机数据交互，并包含配套编写的 `LABVIEW.vi` 界面。
  5. **选题 6（双机通信）**：两台 S7-1200 PLC 之间建立 S7 单边/双边通信（`GET`/`PUT` 或 `TSEND_C`/`TRCV_C`），实现分布式数据同步与联锁控制。
- **软件环境**：
  - PLC 工程均基于 **Siemens TIA Portal V15.1** 开发（工程文件为 `.ap15_1`），建议安装 V15.1 或更新版本；
  - 选题 5 上位机需配合相应版本的 **LabVIEW** 打开运行。

## 课程要求与避坑指南

结合实际修读经验，以下细节直接影响考核成绩与调试效率，务必特别留意：

### 1. 考勤签到（重中之重）
- 本实践课程平时考勤抓得**非常严格**；
- 采用 **学习通线上打卡 + 现场纸质签到表签字** 双重核验，每天上下午都有严格的签到窗口；
- 切勿迟到、早退或漏签，缺卡会直接影响平时成绩甚至导致实践资格受限。

### 2. 硬件接线与联调安全
- **强电安全**：变频器动力输入/输出端、电机主回路涉及 220V/380V 交流电，接线时**必须先拉闸断电**，接完反复检查无短路、无反接再上电；严禁带电插拔接线端子。
- **PLC 固件版本匹配**：博途工程组态中的 PLC 固件版本（如 V4.2、V4.4 等）若高于实验台现场设备的实际固件版本，会导致程序无法下载或报错。调试前先在博途“在线与诊断”中查看现场硬件固件，若版本不一致，可在设备组态中右键“更改设备/固件版本”进行降级匹配。
- **网段与 IP 规划**：双机通信与 G120 联调时，务必提前给各设备规划好同网段且不冲突的静态 IP（包括自己电脑的本地网卡 IP）。若搜索不到设备，检查网线是否插紧以及杀毒软件/防火墙是否拦截了 Profinet 组播广播。

### 3. 验收答辩与期末大报告
- **成绩构成**：平时考勤 + 现场台位动作演示验收 + 期末综合实践大报告。
- **台位验收**：做完一个题目即可找老师进行现场演示验收，老师通常会现场抽查梯形图/SCL 核心控制逻辑，并要求临时更改设定值（如改温控设定、改电机脉冲步数或变频器频率）观察实际动作，建议组内对程序逻辑做到心中有数。
- **大报告规范**：期末大报告要求完整严谨，必须包含：
  - 完整的电气原理图与硬件配置清单；
  - 规范详细的 I/O 地址分配表及符号表；
  - 核心控制流程图与梯形图/SCL 关键段落说明；
  - 实际调试得到的曲线波形与上位机/示波器截图（如 PID 阶跃响应曲线、步进定位波形等）。
