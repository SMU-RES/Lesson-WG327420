## 课程修读与避坑指南（学长实战经验）

### 1. 选题机制与选做建议
- 指导书上写的是“**6 选 4**”，但实际 5 个核心题目都做了：
  - 第 1 个题目（红绿灯/电梯/洗衣机）和之前《工业可编程控制器综合实践》做的内容完全一样，相当于减去一个做剩下的 5 个；
  - **电梯 vs 红绿灯**：非常建议选红绿灯，不建议选手做电梯。手做电梯的难度远大于红绿灯（当然如果全盘使用 Openness 和 AI 辅助完成，难度差别不大）；
  - 本仓库收录了实际完成的 5 个选题完整工程（温控、电机、G120、LabVIEW、双机通信）。

### 2. 硬件与电脑避坑（关键）
- **部分硬件设备是坏的**：截止目前实验台很多硬件（尤其是温控设备，有好几套温度控制硬件是坏的）存在硬件故障。如果程序写出来不能正常运行，注意排查是不是台位硬件本身故障，不一定是自己代码的问题；
- **自带电脑更稳妥**：实验室电脑比较卡，容易卡死甚至出现蓝屏导致未保存的项目丢失；
  - 建议自己带笔记本电脑；
  - 自带电脑直接插网线连接 PLC，新版旧版博途都可以控制设备；如果用实验室电脑新版打不开旧版工程；
  - 轻薄本注意是否自带网口，没有网口提前买一个 USB/Type-C 转网口接头，必须使用网口接入通信。

### 3. 考勤签到
- 考勤抓得严格；
- 采用 **学习通线上签到 + 现场纸质版签到表签到** 双重考勤，务必注意按时打卡。

### 4. 考核形式
- 不设期末闭卷笔试；
- 考核方式为 **现场台位答辩 + 提交综合实践大报告**，难度不大。
